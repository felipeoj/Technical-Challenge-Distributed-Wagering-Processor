# Wagering Processor

Servico financeiro distribuido para processar transacoes de apostas
(BET, WIN, LOSS, REFUND, ROLLBACK) com idempotencia persistente,
concorrencia entre instancias e outbox transacional.

## Stack

Bun, TypeScript (strict), NestJS, MikroORM, PostgreSQL, AWS SQS (LocalStack), Docker Compose.
